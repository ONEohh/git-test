# 文档结构与提纲规范 (Structure Blueprint)

## 3.1 元结构原则
所有文档遵循"倒金字塔+模块化"原则：
- 顶部20%：核心结论/主旨全景（让读者30秒内抓住重点）
- 中部60%：分层论证/展开（每部分可独立阅读）
- 底部20%：总结升华/行动号召（回扣开头，形成闭环）

## 3.2 通用章节骨架
```text
[封面/标题区]
  └─ 标题公式：核心对象 + 关键动作 + 价值指向（限20字内）

[摘要/导语区]（占全文5-10%）
  └─ 三要素：背景（为何写）+ 核心发现（是什么）+ 结构预告（怎么读）

[主体论证区]（占全文60-70%）
  └─ 采用"MECE原则"：相互独立，完全穷尽
  └─ 每章遵循"论点→论据→论证→小结"四步循环

[边界/局限区]（占全文5%，可选）
  └─ 主动声明本文未覆盖的内容或存在的局限

[结论/行动区]（占全文10-15%）
  └─ 不引入新论据，仅整合前文并指向未来
```

## 3.3 《水浒传》读书心得定制模板（3000字+）

```text
1. 引言：从梁山泊到数字中国（300字）
   - 阅读《水浒传》的契机
   - 核心问题：团队协作精神如何与软件工程实践相结合？

2. 《水浒传》中的团队精神密码（600字）
   - "忠义"精神的内涵与价值
   - 梁山好汉的分工协作与组织管理
   - 团队凝聚力的形成机制

3. 软件工程专业素养的时代要求（600字）
   - 专业知识体系（数据结构、算法、系统设计）
   - 团队协作能力（敏捷开发、项目管理、沟通协调）
   - 国家安全意识与责任担当

4. 从梁山泊到网络安全：技术报国的实践路径（800字）
   - 国家网络安全战略与需求
   - 软件工程在网络安全中的应用场景
   - 案例分析：国产操作系统、密码技术、安全防护体系

5. 个人成长与时代使命（500字）
   - 专业学习规划
   - 团队协作能力培养
   - 长期职业愿景

6. 结语：在代码与江湖之间寻找平衡（200字）
```

## 3.4 段落微观结构
- **起承转合标记**：每段开头使用逻辑路标词（"具体而言"、"反观之"、"值得注意的是"）
- **信息密度**：每段不超过5个信息点，超过则拆分
- **过渡规则**：段与段之间必须有显性连接词或隐性逻辑链（禁止硬跳转）

## 3.5 长度控制公式
- 总字数：3000字以上
- 各部分占比：引言10%、文学分析20%、专业论述20%、实践路径30%、个人规划15%、结语5%
