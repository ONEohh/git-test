# 文档结构与提纲规范 (Structure Blueprint)

## 3.1 元结构原则
演讲稿遵循"开头-主体-结尾"三段式原则：
- 开头(15%)：吸引注意力，点明核心价值
- 主体(70%)：分层论证，展示核心内容
- 结尾(15%)：总结升华，呼吁行动

## 3.2 演讲时间分配（3分钟/600字左右）

| 部分 | 时长 | 字数 | 内容要点 |
|-----|-----|-----|---------|
| 开场 | 30秒 | 100字 | 问候、自我介绍、项目名称、核心价值 |
| 痛点分析 | 40秒 | 130字 | 基层眼病筛查现状、问题分析 |
| 技术方案 | 60秒 | 200字 | 核心技术路线、差异化优势 |
| 测试成果 | 40秒 | 130字 | 关键数据、性能指标 |
| 总结展望 | 10秒 | 40字 | 项目意义、未来方向 |

## 3.3 演讲稿定制模板

```text
1. 开场（30秒/100字）
   - 问候与自我介绍
   - 项目名称与一句话定位
   - 核心价值提炼

2. 痛点分析（40秒/130字）
   - 当前基层眼病筛查面临的困境
   - 数据支撑（如：我国糖尿病患者超1.4亿）
   - 现有解决方案的不足

3. 技术方案（60秒/200字）
   - 核心技术路线：ResNet50+CLAHE+Grad-CAM+DeepSeek
   - 四大差异化优势：低成本、多病种、可解释、通俗解读
   - 系统架构简介

4. 测试成果（40秒/130字）
   - 准确率：94.28%
   - 推理速度：0.76秒
   - CLAHE消融实验效果：+4.4%
   - 并发测试：50用户稳定支持

5. 总结展望（10秒/40字）
   - 项目意义
   - 未来方向（移动端、纵向追踪）
```

## 3.4 段落微观结构
- **起承转合标记**：使用逻辑路标词（"首先"、"其次"、"值得注意的是"）
- **信息密度**：每段不超过3个信息点，超过则拆分
- **过渡规则**：段与段之间必须有显性连接词

## 3.5 长度控制公式
- 总字数：≤600字（3分钟×200字/分钟）
- 各部分占比：开场15%、痛点20%、技术35%、成果25%、总结5%
